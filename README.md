# Azure Vibe Quiz

"Build a modern, responsive React + Tailwind CSS web app called 'AzureVibe Prep'. It is an unofficial AZ-900 Exam Prep Smart Quiz Builder.

Features:

A clean, modern UI with a purple/blue gradient 'vibe' theme.

A prominent disclaimer at the top: '⚠️ Unofficial AZ-900 Prep Tool. Not affiliated with Microsoft. For educational purposes only.'

A quiz interface that shows one question at a time with 4 multiple-choice options.

When the user clicks an answer, instantly show if it's Correct (green) or Incorrect (red), and display a clear, simple explanation of WHY the answer is right or wrong.

A 'Next Question' button to proceed.

A progress tracker (e.g., 'Question 2 of 5').

Include a small 'African Context' tip box below the explanation for each question to make it relatable (e.g., comparing cloud redundancy to local mobile money systems).

Please pre-load the app with 5 high-quality, original AZ-900 practice questions covering Cloud Concepts, Azure Architecture, and Resource Management. Make the code clean and ready to deploy."

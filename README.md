# 🚀 AzureVibe Prep: Smart AZ-900 Quiz Builder

> ⚠️ **Disclaimer:** This is an unofficial study tool. It is not affiliated with, endorsed by, or sponsored by Microsoft. All content is based on the public AZ-900 skills outline.

##  The Problem
Learners often practice AZ-900 questions but don't understand *why* an answer is right or wrong. Abstract cloud concepts can also feel disconnected from local realities for African learners.

## 💡 The Solution
AzureVibe Prep is a smart quiz app that provides instant, clear explanations for every answer. It uniquely includes relatable real-world analogies (including African contexts like M-Pesa and local markets) to make abstract cloud concepts stick.

## 🛠️ Tech Stack (Vibe Coding)
- **Frontend:** React + Tailwind CSS
- **Build Tool:** Lovable.dev (AI-assisted rapid prototyping)
- **Live Demo:** [azure-vibe-quiz.lovable.app](https://azure-vibe-quiz.lovable.app)

## 🎯 How It Meets the Hackathon Theme
- **Learning Value:** Accurate, original questions with deep explanations.
- **Prompt Engineering:** Built entirely using AI-assisted development tools via precise prompting.
- **UX & Vibes:** Clean, modern interface with instant feedback and a clear unofficial disclaimer.
- **African Context:** Integrates local analogies to demystify cloud concepts.
